# Cron 表达式解析 (cron)

标准 5 段 cron 表达式的解析与匹配，支持范围、步进、列表、名称别名等常用语法。

## API

```
*    *    *    *    *
│    │    │    │    │
│    │    │    │    └── day of week (0 - 6, 0 = Sunday)
│    │    │    └─────── month (1 - 12)
│    │    └──────────── day of month (1 - 31)
│    └───────────────── hour (0 - 23)
└────────────────────── minute (0 - 59)
```

```c
struct cron_t {
	uint64_t minute;
	uint32_t hour;
	uint32_t day;
	uint16_t month;
	uint8_t week;
	uint8_t restricted;
};

int cron_parse(struct cron_t * cron, const char * expr);
int cron_match(struct cron_t * cron, int minute, int hour, int day, int month, int week);
```

- `cron_parse` - 解析表达式并填充 `cron_t`，成功返回 `1`，失败返回 `0`；失败时 `cron_t` 内容不可信，应以返回值为准
- `cron_match` - 判断给定时间是否命中，命中返回 `1`，否则返回 `0`

## 表达式格式

表达式由 5 个字段组成，以空格分隔：

| 字段 | 范围 | 说明 |
| --- | --- | --- |
| 分 | 0-59 | 分钟 |
| 时 | 0-23 | 小时，从 0 起计 |
| 日 | 1-31 | 每月第几天，从 1 起计 |
| 月 | 1-12 或 JAN-DEC | 月份，可用名称缩写 |
| 周 | 0-6 或 SUN-SAT | 星期几，0=周日（7 等价于 0）|

每个字段支持以下写法：

| 写法 | 说明 |
| --- | --- |
| `*` | 任意值 |
| `?` | 任意值（等同于 `*`，表示该字段不限制）|
| `n` | 单个值 |
| `a-b` | 范围 |
| `a-b/s` | 范围内按步进 `s` 取值 |
| `*/s` | 任意值按步进 `s` 取值 |
| `a/s` | 从 `a` 到字段最大值按步进 `s` 取值，如 `5/15` 表示 5,20,35,50 |
| `a,b,c` | 列表，组合上述任意写法 |

月份与星期支持不区分大小写的 3 字母缩写：`JAN`..`DEC`、`SUN`..`SAT`。

## 日与星期

### `7` 等价于 `0`

星期字段中 `7` 是 `0`（周日）的别名，二者等价。因此 `0-7`、`0,7`、`1-7` 都能正确表示"包含周日"。

### 组合规则

遵循 Vixie cron 语义：

- 当**日**和**星期**都被显式指定（均非 `*`/`?`）时，命中其中任一即匹配（**或**）
- 否则两者需同时匹配（**与**）

例如 `30 4 1,15 * 5` 表示每月 1 号、15 号或每周五 4:30 执行。

## 使用示例

### 基本用法

```c
struct cron_t cron;
struct wallclock_time_t tm;

if(cron_parse(&cron, "30 3 * * *"))       /* 每天 3:30 */
{
	wallclock_gettime(&tm, NULL);
	if(cron_match(&cron, tm.minute, tm.hour, tm.day, tm.month, tm.week))
	{
		/* 执行定时任务 */
	}
}
```

`wallclock_time_t.week` 的定义为 `(自 1970-01-01 起的天数 + 4) % 7`，即 `0 = 周日`，与 cron 标准一致，可直接传入 `cron_match`。调度上通常每分钟调用一次 `cron_match` 进行检查。

### 常用表达式

| 表达式 | 含义 |
| --- | --- |
| `*/5 * * * *` | 每 5 分钟 |
| `0 * * * *` | 每小时整点 |
| `30 3 * * *` | 每天 3:30 |
| `0 9 * * 1` | 每周一 9:00 |
| `0 0 1 * *` | 每月 1 号 0:00 |
| `0 0 * * 5` | 每周五 0:00 |
| `0 0 * * 0` | 每周日 0:00（`7` 同义）|
| `0 0 1 1 *` | 每年 1 月 1 号 0:00 |
| `30 4 1,15 * 5` | 每月 1、15 号或每周五 4:30 |
| `*/15 * * * *` | 每 15 分钟 |
